1. untuk pembuatan halaman selalu file css dan tsx logic nya dipisah
2. buat folder component khusus menampung semua component game khusus dengan fungsi
3. buat css seresponsif mungkin secara resolusi mobile , laptop , monitor.
4. menggunakan satuan vh atau vw dalam responsif css nya 
5.jangan membuat responsif potrait karena semua akan dirender secara landscape
6.jangan menggunakan satuan px dalam responsif css dikarenakan ketika di zoom out dan Zoom in pada web komponen akan membesar atau mengecil jadi menggunakan 
vw dan vh saja karena satuan itu katanya bisa otomatis menegetahui berapa px dirender sesuai device responsif 
7. untuk responsif utamakan media querry tampilan mobile, laptop, dan monitor 
8. semua asset ada di folder asset 
9. gunakan font secara global rubik one untuk setiap text
10. untuk responsif laptop juga khususkan ada laptop sedang dan layar agak besar, jadi saya mau komponen semua responsif

12. untuk setiap css class selector beda beda per halaman walaupun hasil clone harus dibedakan nama class nya agar tidak tertumpuk jsx nya
13. untuk bahasa dalam web menggunakan bahasa jawa untuk anak kecil , karena game ini untuk anak anak smp sma atau anak sekolah
 
14 untuk aturan px dan presentase dalam css hanya boleh digunakan untuk elemen background saja dan tiru contoh-bg.css saja untuk bg only , untuk komponen selain background tidak boleh dan tetap mengikuti aturan 
15. jika membuat suatu komponen tombol,form,dll harus pertimbangkan warnanya match dan pertimbangkan semua responsif size dan eyecatching di semua resposif , dan beri spacing antara komponen satu sama alain jangan berdempet 
16. PENGUNCIAN ZOOM & KONSISTENSI DEVICE (ZOOM-LOCK):
    - Tampilan (look) pada laptop kecil, laptop sedang, laptop besar, dan monitor HARUS SAMA PERSIS dan ukurannya terkunci secara proporsional.
    - Saat browser di-zoom in (110%, 125%, 150%, hingga 175%) atau di-zoom out, komponen (form, tombol, background, teks) TIDAK BOLEH berpindah tempat, bergeser dari posisinya di background, atau membesar/meloncat secara aneh.
    - Media query mobile landscape WAJIB dilindungi dengan guard pointer layar sentuh (misal: `(pointer: coarse)`) agar saat layar desktop di-zoom in tinggi (di mana pixel width mengecil), sistem TIDAK SALAH mendeteksi laptop/monitor sebagai HP dan TIDAK mengganti background atau layout secara mendadak.
    - Nilai breakpoint untuk laptop sedang dan monitor/layar besar harus diseragamkan nilai proporsi `vw`/`vh`-nya agar tetap stabil dan terkunci konstan di semua level zoom.
